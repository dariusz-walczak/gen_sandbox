# Register Entry Annotation {#register_entry_annotation}

A __Register Entry Annotation__ is a supplement to a __[Register Entry](#register_entry)__, most often in a form of a marginal note, that typically corrects errors in the entry or provides information about other events associated with the __[Primary Participants](#primary_participant)__.
