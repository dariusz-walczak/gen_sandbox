# Primary Entry Language {#primary_entry_language}

A __Primary Entry Language__ is a __[Register Entry Language](#register_entry_language)__ in which the main facts of a __[Register Entry](#register_entry)__ are recorded, including names, places, dates, ages, and administrative information, as well as any prose connecting those facts in entries of a prose format. A __[Register Entry](#register_entry)__ has exactly one __Primary Entry Language__.
