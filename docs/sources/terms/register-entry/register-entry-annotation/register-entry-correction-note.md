# Register Entry Correction Note {#register_entry_correction_note}

A __Register Entry Correction Note__ is a type of __[Register Entry Annotation](#register_entry_annotation)__ that corrects language or factual errors that the __[Registrar](#registrar)__, __[Informant](#informant)__, __[Witnesses](#witness)__, or other __[Individuals](#individual)__ participating in the registration process spot in the __[Register Entry](#register_entry)__. The correction is typically added immediately after the __Register Entry__ is created and, as a result, is typically undated.
