# Register Entry Correction Note {#register_entry_correction_note}

A __Register Entry Correction Note__ is a type of [Register Entry Annotations](#register_entry_annotation) that corrects language or factual errors spotted in the [Register Entry](#register_entry) by the [Registrar](#registrar), [Informant](#informant), Witnesses, or other persons participating in the registration process. The correction is typically added immediately after the [Register Entry](#register_entry) creation and due to this fact is typically undated.
