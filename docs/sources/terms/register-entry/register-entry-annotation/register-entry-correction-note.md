# Register Entry Correction Note {#register_entry_correction_note}

A __Register Entry Correction Note__ is a type of __[Register Entry Annotations](#register_entry_annotation)__ that corrects language or factual errors spotted in the __[Register Entry](#register_entry)__ by the __[Registrar](#registrar)__, __[Informant](#informant)__, Witnesses, or other persons participating in the registration process. The correction is typically added immediately after the __[Register Entry](#register_entry)__ creation and due to this fact is typically undated.
