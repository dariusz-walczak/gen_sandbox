# Digitized Register Book Page Region {#digitized_register_book_page_region}

A __Digitized Register Book Page Region__ is a geometric area within a __[Digitized Register Book Page](#digitized_register_book_page)__, defined by its shape and relative position on the page. The shape may be regular (e.g., a rectangle) or irregular (e.g., a polygon), and is specified by parameters appropriate to that shape.
